# G10 Companion — project state

Короткое стабильное состояние проекта для будущих агентных итераций. Обновлять только при реально устойчивых изменениях архитектуры/протокола.

## Текущая линия

- Приложение: G10 Companion / G10-lab для YADEA G10.
- Текущий публично описанный кандидат: `v0.7.0 Alpha`.
- Android-приложение обновляется поверх предыдущей версии с тем же `applicationId` и постоянной тестовой подписью, чтобы сохранялись профиль батареи, обучение и история.
- Сборка: JDK 17, Gradle 8.13, AGP 8.13.2; GitHub Actions собирает debug APK.

## Главные рабочие сценарии

1. **G10 DRIVE** — скорость, главный прогноз в км с диапазоном, текущая поездка и остаток после планового маршрута в км.
2. **МАРШРУТ** — OSM-карта, точка назначения, варианты маршрута, поездка в одну сторону/туда-обратно, прогноз остатка.
3. **ПОЕЗДКА** — GPS-запись, статистика, история и экспорт.
4. **БАТАРЕЯ** — профиль, обучение, просадка, оценочный SOC и тренд SOH.
5. **ТРЕК GPS** — техническая геометрия поездки.
6. **LAB** — пассивная диагностика BLE-протокола и работа только с подтверждёнными безопасными командами.

## Маршрут и прогноз

- До трёх вариантов велосипедного маршрута. Автомобильный fallback убран; при недоступном сервисе остаётся ручной километраж.
- Поправки прогноза: профиль езды, температура, масса водителя с грузом, набор высоты.
- Результат должен быть понятным: можно ехать / на границе запаса / заряда не хватит.
- До накопления качественных поездок используется заводской профиль; затем модель может опираться на персональную эффективность конкретного самоката.
- Недостаточные/плохие поездки не использовать для обучения.
- При отсутствии карты пользователь должен иметь возможность работать с введённым вручную километражем.

## BLE — подтверждённое

Профиль:

- BEKEN SAS BK-BLE-1.0;
- FW 6.1.2 / SW 6.3.0;
- сервис FFF0;
- FFF1 — Write Without Response;
- FFF2 — Read / Notify.

Подтверждённые команды режима:

- `F0 4C 03 01` — ECO;
- `F0 4C 03 02` — SPORT;
- `F0 4C 03 03` — RACE.

Использовать только после получения телеметрии, при скорости 0 км/ч и отсутствии признака движения.

## BLE — не подтверждено / не отправлять

Не отправлять неизвестные кадры или неподтверждённые команды для света, рекуперации, TCS, Zero Start, Cruise, LOCK/UNLOCK и OTA/OAD. Команду `F0 4D 13` также не считать подтверждённой управляющей командой.

## Ограничения батарейной модели

- FFF2 пока не подтверждает ток и BMS SOC.
- Оценочный SOC не называть точным BMS SOC.
- До обучения показывать безопасный диапазон/неопределённость.
- Не выдавать выдуманный Wh/км.
- SOH отображать как оценочный тренд, а не лабораторное измерение.
- Уверенность увеличивать только на качественных поездках.

## Карта и приватность

- Тайлы: OpenStreetMap.
- Поиск адреса: Nominatim по явному действию пользователя, с локальным кэшированием.
- Маршрут: открытый велосипедный сервис FOSSGIS; автомобильный OSRM не подставляется автоматически.
- У приложения нет собственного сервера/аккаунта для пользовательских маршрутов.

## Ключевые файлы

- `MainActivity.java` — UI и интеграция экранов.
- `G10BleManager.java` — BLE.
- `TripTracker.java`, `TripAnalysisEngine.java` — поездки/GPS.
- `BatteryCoach.java` — батарейная модель.
- `RouteEnergyEstimator.java` — прогноз маршрута.
- `route_map.html` — карта/поиск/маршрут.
- `core-tests/` — расчётные тесты.

## Пакет v0.7

- Внизу 4 раздела: Приборы / Маршрут / Поездки / Ещё. Батарея, LAB и GPS-трек доступны через Ещё.
- Главный прогноз и вкладка Батарея используют один RouteEnergyEstimator; подъём применяется к плану маршрута отдельно.
- Нулевой резерв отличён от отсутствия данных. Персональная модель включается минимум с 3 поездок.
- Новые обучающие поездки: ≥1 км, ≥180 с движения, GPS ≥70%, падение ≥0.3 В и прежние границы эффективности.
- G10Protocol проверяет кадр 24 22 длиной 20 байт; смена режима требует телеметрию ≤2 с и паузу ≥750 мс.
- Очередь GATT не считается ACK. Запрошенный режим отображается отдельно; режим в CSV остаётся неизвестным до расшифровки ACK.
- CCCD подтверждается callback; старые сессии игнорируются; GPS не получает устаревшую телеметрию.
- PROTOCOL_DETECT записывает смену семейства без копии HEX. Прежний формат столбцов сохранён.
- Исправлены SRI Leaflet CSS, HTTPS-контекст карты, гонка ответов, повторные запросы при каждом GPS и размер скрытой карты.
- Во время записи экран остаётся включённым. Фоновый foreground service в этот пакет не входит.
- Исследование команд: docs/COMMAND_RESEARCH_2026-09-08.md; доступно офлайн в приложении.
