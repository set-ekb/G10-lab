# G10 Companion v0.6.0 Alpha

Персональное бортовое приложение для YADEA G10. Версия v0.6 продолжает v0.5
с тем же `applicationId` и той же подписью: профиль батареи, обучение и история
сохраняются при обычном обновлении APK.

## Главное в v0.6

- новый компактный экран **G10 DRIVE** с крупной скоростью, SOC, запасом хода
  и итогом выбранного маршрута;
- отдельная вкладка **МАРШРУТ** с картой OpenStreetMap;
- выбор точки нажатием на карту или единичным поиском адреса;
- до трёх вариантов велосипедного маршрута с выбором нужной длины;
- открытие выбранной точки в установленном навигаторе телефона;
- расчёт поездки в одну сторону или туда-обратно;
- три профиля расхода: экономичный, сбалансированный и быстрый;
- поправки на температуру, массу водителя с грузом и набор высоты;
- понятный результат: `МОЖНО ЕХАТЬ`, `НА ГРАНИЦЕ ЗАПАСА` или
  `ЗАРЯДА НЕ ХВАТИТ`;
- прогноз остатка SOC по прибытии с безопасным диапазоном;
- заводской профиль G10: 48 В, 15,6 А·ч и заявленный запас 31 миля;
- после накопления поездок заводская модель автоматически заменяется
  персональной эффективностью конкретного самоката и водителя;
- параметры маршрута входят в резервную копию JSON;
- отдельные автоматические тесты ядра маршрутного прогноза.

## Полезные функции предыдущей версии

- фильтрация GPS-скачков и оценка качества записи;
- дистанция, реальное время движения, скорость, набор и сброс высоты;
- доли ECO / SPORT / RACE и индекс нагрузки;
- анализ начального, минимального и конечного напряжения;
- оценка просадки под нагрузкой и восстановления после остановки;
- оценочный SOC, обучаемый запас хода и тренд SOH;
- экспорт поездки в CSV, GPX, KML и TXT;
- резервная копия профиля, обучения, маршрута и истории в JSON;
- диагностический LAB с HEX, GATT, метками и экспортом CSV.

## Вкладки

- **ГЛАВНАЯ** — приборная панель для поездки.
- **МАРШРУТ** — карта, варианты пути и прогноз заряда по прибытии.
- **ПОЕЗДКА** — запись, статистика, история и экспорт.
- **БАТАРЕЯ** — профиль, обучение, просадка, SOC и тренд SOH.
- **ТРЕК GPS** — техническая геометрия записанной поездки.
- **LAB** — диагностика BLE-протокола без отправки неизвестных команд.

## Карта и приватность

Карта загружает тайлы OpenStreetMap. Поиск адреса выполняется через Nominatim
только после нажатия кнопки `НАЙТИ` и кэшируется на телефоне. Велосипедный
маршрут рассчитывает открытый сервер FOSSGIS; установлен лимит не чаще одного
запроса в секунду. Если он недоступен, используется дорожный OSRM как запасной
вариант. Адрес и точки маршрута передаются этим картографическим сервисам, но
приложение не имеет собственного сервера и аккаунта.

Построенный маршрут остаётся рекомендацией. Перед поездкой нужно проверить
дорожные знаки, покрытие и допустимость движения самоката на выбранном участке.

## Подтверждённый профиль G10

- BEKEN SAS BK-BLE-1.0;
- FW 6.1.2 / SW 6.3.0;
- сервис FFF0;
- FFF1 — Write Without Response;
- FFF2 — Read / Notify.

Подтверждённые команды режима:

- `F0 4C 03 01` → ECO;
- `F0 4C 03 02` → SPORT;
- `F0 4C 03 03` → RACE.

Они разрешены только после получения телеметрии, при скорости 0 км/ч и
отсутствии признака движения.

## Что намеренно не отправляется

Неизвестные кадры 55 AA / 5A A5, свет, рекуперация, TCS, Zero Start,
Cruise ON/OFF, LOCK/UNLOCK и OTA/OAD остаются объектами только пассивного
анализа до подтверждения точных команд. Команда `F0 4D 13` также не отправляется:
в тесте 12.08.2026 отдельного ответа FFF2 после неё не обнаружено.

## Границы прогноза батареи

FFF2 пока не даёт подтверждённый ток и BMS SOC. Поэтому приложение:

- не называет оценочный SOC точным процентом BMS;
- до обучения показывает расширенный безопасный диапазон;
- не выдаёт выдуманный расход Wh/км;
- показывает тренд SOH, а не лабораторный SOH батареи;
- повышает уверенность после 3–5 качественно записанных поездок.

Лог `g10_trip_20260813_125258.csv` содержит только 27 GPS-точек, скорость до
6 км/ч и большие паузы, поэтому не используется как обучающая поездка.

## Проверка и сборка

Локальный тест чистого Java-ядра без Android SDK:

```bash
bash scripts/run_core_tests.sh
```

GitHub Actions собирает debug APK на JDK 17, Gradle 8.13 и AGP 8.13.2.
Имя артефакта:

`G10-Companion-v0.6.0-alpha-debug`

Файл `app/g10-debug.keystore` — постоянная личная тестовая подпись. Его нужно
сохранять, чтобы следующие APK устанавливались поверх v0.5 без удаления данных.

## Ограничения Alpha

- карта и новый расчёт маршрута требуют интернет;
- при недоступности карты километраж можно ввести вручную;
- полноценная пошаговая навигация выполняется внешним навигатором;
- GPS-трекинг работает, пока Activity приложения жива; foreground service для
  гарантированной фоновой записи остаётся задачей следующей итерации.
