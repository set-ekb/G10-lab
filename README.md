# G10 BLE Lab v0.3

Диагностическое Android-приложение для пассивного чтения BLE-телеметрии YADEA G10.

## Что показывает

- скорость из `FFF2 byte[12]`, 0-based index;
- `RAW speed` из little-endian `byte[10..11]`;
- движение: `byte[18] & 0x02`;
- круиз: `byte[18] & 0x04`;
- тормоз: `byte[18] & 0x08`;
- HEX пакетов FFF2;
- количество пакетов;
- метки теста: СТОИТ / КОЛЕСО / ТОРМОЗ / ECO / SPORT / RACE;
- экспорт CSV.

## Важно

Приложение **не отправляет прикладные команды в FFF1**.

Единственная BLE-запись — стандартная запись CCCD-дескриптора FFF2 для включения Notify.

## BLE UUID

- Service FFF0: `0000fff0-0000-1000-8000-00805f9b34fb`
- FFF1: `0000fff1-0000-1000-8000-00805f9b34fb` — обнаруживается, но не записывается
- FFF2: `0000fff2-0000-1000-8000-00805f9b34fb` — Notify
- CCCD: `00002902-0000-1000-8000-00805f9b34fb`
