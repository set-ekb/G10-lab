# G10 Companion v0.5.0 Alpha

Следующая тестовая итерация бортового приложения для YADEA G10. Она продолжает
v0.4.0 с тем же `applicationId`, поэтому профиль батареи, обучение и история
сохраняются при обычном обновлении APK с той же подписью.

## Что добавлено в v0.5

- отдельное чистое Java-ядро анализа поездки с автоматическими тестами;
- фильтрация GPS-скачков, оценка качества записи и времени реального движения;
- набор и сброс высоты, индекс нагрузки, доли ECO / SPORT / RACE;
- анализ начального, минимального и конечного напряжения;
- оценка просадки под нагрузкой и восстановления после остановки;
- локальный текстовый вердикт с объяснимыми причинами;
- оценочный SOC по профилю напряжения;
- тренд SOH только после 5 обучающих поездок — это не лабораторный SOH BMS;
- раздельное обучение эффективности по режимам движения;
- поправка прогноза на вручную указанную температуру;
- редактируемый профиль: полный заряд, резерв, ёмкость, температура и циклы;
- экспорт поездки в CSV, GPX, KML и TXT-отчёт;
- резервная копия настроек, обучения и истории в JSON с восстановлением;
- системный выбор места сохранения, включая Google Drive на телефоне;
- LAB показывает изменившиеся индексы байтов и скорость потока пакетов;
- ограничение LAB в памяти до 5000 строк;
- история увеличена до 50 завершённых поездок;
- стабильная личная debug-подпись для обновлений без потери локальных данных.

## Вкладки

- **ГЛАВНАЯ** — BLE, скорость, напряжение, режим, круиз и тормоз.
- **ПОЕЗДКА** — ручной/автоматический старт, статистика и четыре формата экспорта.
- **КАРТА** — локальная геометрия GPS-трека без сетевой подложки.
- **BAT AI** — SOC, тренд SOH, запас хода, профиль и подробный разбор.
- **LAB** — HEX, GATT, passive protocol detector, метки и CSV.

## Подтверждённый профиль G10

- BEKEN SAS BK-BLE-1.0;
- FW 6.1.2 / SW 6.3.0;
- сервис FFF0;
- FFF1 — Write Without Response;
- FFF2 — Read / Notify.

Подтверждённые команды режима:

- `F0 4C 03 01` → ECO;
- `F0 4C 03 02` → SPORT;
- `F0 4C 03 03` → RACE.

Они разрешены приложением только после получения телеметрии, при скорости
0 км/ч и отсутствии признака движения.

## Итог последнего теста 12.08.2026

В файле `g10_ble_20260812_174109.csv` команда `F0 4D 13` была отправлена один
раз. В 32 следующих кадрах FFF2 не обнаружен отдельный или устойчиво
отличающийся ответ: менялся только байт напряжения 48.4/48.5 В. Поэтому команда
не считается подтверждённым запросом круиза и в v0.5 не отправляется.

## Что намеренно не отправляется

Неизвестные кадры 55 AA / 5A A5, свет, рекуперация, TCS, Zero Start,
Cruise ON/OFF, LOCK/UNLOCK и OTA/OAD остаются только объектами пассивного
анализа до подтверждения точных команд.

## Границы Battery AI

FFF2 пока не даёт подтверждённый ток и BMS SOC. Поэтому приложение:

- не выдаёт выдуманный расход Wh/км;
- помечает SOC как оценку по напряжению;
- показывает не абсолютный лабораторный SOH, а тренд относительно лучших
  сопоставимых поездок;
- повышает уверенность прогноза постепенно, по мере накопления поездок.

## Проверка и сборка

Локальный тест аналитики без Android SDK:

```bash
bash scripts/run_core_tests.sh
```

GitHub Actions выполняет этот тест, затем собирает debug APK на JDK 17,
Gradle 8.13 и AGP 8.13.2. Имя артефакта:

`G10-Companion-v0.5.0-alpha-debug`

Файл `app/g10-debug.keystore` предназначен только для личных тестовых сборок.
Его нужно сохранять во всех следующих исходных версиях, иначе Android не даст
установить обновление поверх старой APK.

Если уже установленная v0.4 была подписана другим случайным debug-ключом,
Android может один раз потребовать удалить её перед установкой v0.5. Начиная с
этой версии ключ закреплён, поэтому последующие обновления смогут сохранять
локальные данные. Если v0.4 не устанавливалась, этого переходного ограничения нет.

## Ограничение текущей Alpha

GPS-трекинг работает, пока Activity приложения жива. Полноценный foreground
service для гарантированной фоновой записи запланирован на следующую итерацию.
