G10 BLE Lab v0.3.4 — Cruise Query

ЗАМЕНИТЬ РОВНО 3 ФАЙЛА:
1) app/src/main/java/com/g10blelab/app/MainActivity.java
2) app/build.gradle.kts
3) .github/workflows/main.yml

Новое:
- диагностическая кнопка QUERY CRUISE — F0 4D 13
- это запрос состояния, а не команда включения/выключения
- распознавание короткого ответа F1 13 ... state
- state byte берётся из packet[3]:
  01 -> Круиз разрешён: ДА
  00 -> Круиз разрешён: НЕТ
- ответ отдельно пишется в CSV как PROTOCOL_RX / CRUISE_CONFIG_RESPONSE
- ECO / SPORT / RACE, батарея и Cruise Active из v0.3.3 сохранены
- никаких Cruise ON/OFF, LOCK/UNLOCK, Zero Start или OTA

ТЕСТ:
1) Самокат стоит, скорость 0 км/ч.
2) Круиз на приборке сейчас РАЗРЕШЁН.
3) Подключить приложение и дождаться FFF2.
4) Очистить журнал.
5) Нажать QUERY CRUISE один раз.
6) Подождать 5 секунд.
7) Если появится "Ответ Cruise: РАЗРЕШЁН/ЗАПРЕЩЁН" — экспортировать CSV.
8) Если ответа нет — тоже экспортировать CSV; повторять запрос не нужно.
